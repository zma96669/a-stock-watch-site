# A股盯盘

一个面向 VS Code 的 A 股自选股与分时图扩展。

## 功能

- 沪深 A 股六位代码
- 共用自选股与当前股票
- 状态栏实时价格和涨跌幅
- 固定三大指数走势：上证指数、深证成指、创业板指，显示点位、涨跌幅和迷你分时
- 自选股侧边栏
- 当日价格、均价和分区成交量分时图，显示量比
- 背景指标支持成交额与 MACD 快速切换，`Ctrl+Alt+M` 一键切换
- 腾讯报价默认每 2 秒刷新，当前股票分时默认每 5 秒刷新，失败后自动退避
- Webview 自选股卡片：支持名称搜索、自定义分组、折叠和持仓盈亏
- 固定“我的关注”视图：股票可手动关注，同时保留在原分组
- Explorer 风格的紧凑树状分组、箭头列和缩进引导线
- 自选股、分组、排序和持仓配置可导出并无损迁移到其他电脑
- 支持绑定 GitHub 私有仓库，手动上传和同步自选股配置
- 盘中智能提醒：价格突破/跌破、涨跌幅、量比、换手率、快速异动、持仓盈亏和相对大盘强弱
- 提醒中心支持普通静默、重要弹窗、10 分钟冷却、越线重置和“今日不再提醒”
- 持仓支持买入、部分卖出、加权平均成本和自动清仓归档；清仓记录可查看完整交易流水
- `Ctrl+Alt+Shift+]` 提高背景清晰度，`Ctrl+Alt+Shift+[` 降低背景清晰度
- 可选的实验性代码背景分时图

## 使用

1. 打开活动栏中的“A股盯盘”。
2. 在自选股视图输入股票名称或 `600519` 这样的六位代码。
3. 点击自选股切换当前股票。
4. 执行“A股盯盘：打开分时图”，把面板拖到右侧或底部。

“大盘走势”固定在自选股顶部。点击任一指数，会将分时面板和实验背景切换为对应指数；点击普通股票即可恢复个股走势。

## 盘中提醒

在股票行右侧“···”菜单选择“设置盘中提醒”，可以创建价格、涨跌幅、量比、换手率和 3 分钟快速异动规则。普通提醒只进入提醒中心，重要提醒才使用 VS Code 通知；同一规则触发后默认冷却 10 分钟，条件恢复后再次越线可以重新提醒。命令面板中的“发送测试提醒”可在不开盘时验证通知链路。

## 持仓买卖与清仓

在股票行右侧“···”菜单选择“买入”或“卖出”，输入成交价和股数即可记录交易。支持部分卖出；全部卖出后，该持仓周期会自动归档到列表底部的“已清仓”，显示累计买入、卖出、已实现盈亏和收益率。交易流水会随数据导出和 GitHub 同步迁移。

## 换电脑迁移数据

1. 在旧电脑点击自选股视图标题栏的“数据管理”图标，选择“导出数据”。
2. 把生成的 `.a-stock-watch.json` 文件复制到新电脑。
3. 新电脑安装插件后，再从“数据管理”选择“导入数据”。
4. “完整恢复”会无损还原备份；“智能合并”会保留新电脑已有的股票，重复股票采用备份里的分组和持仓配置。

每次导入前，插件都会在自己的全局存储目录自动生成恢复备份。导入文件不包含背景组件路径、通信令牌等电脑相关数据。

## GitHub 云同步

在自选股视图标题栏点击云同步按钮，首次使用时按 VS Code 提示登录 GitHub。插件会创建仅自己可见的 `a-stock-watch-sync` 私有仓库，并提供“上传到 GitHub”和“从 GitHub 同步”两个手动操作。上传前会检测其他电脑是否更新过云端，发现冲突时不会静默覆盖；从云端同步默认采用智能合并，并且每次同步前都会生成本地恢复备份。

插件只保存仓库关联、文件 SHA 和同步时间，不保存 GitHub Token；解除绑定不会删除远端仓库。

## 实验背景模式

执行“A股盯盘：启用实验背景模式”。该功能会备份并修改 VS Code 工作台文件，可能需要管理员权限，VS Code 更新后可能需要执行“重新安装背景组件”。

关闭或卸载前，应先执行“A股盯盘：关闭实验背景模式”。稳定面板不依赖该功能。

背景底部指标默认显示成交额。需要观察短线动能时，按 `Ctrl+Alt+M` 可切换为 MACD（DIF、DEA 和柱体）；再次按下即可切回成交额。当前选择会保存在用户设置中。

## 数据说明

行情优先来自腾讯财经，东方财富逐项自动兜底；搜索使用东方财富公开搜索接口。数据仅用于个人辅助查看，不保证交易所级实时性，不可用于自动交易。自选股、分组和持仓设置保存在 VS Code 本地。
