# A股盯盘

一个面向 VS Code 的 A 股自选股与分时图扩展。

## 功能

- 沪深 A 股六位代码
- 共用自选股与当前股票
- 状态栏实时价格和涨跌幅
- 自选股侧边栏
- 当日价格、均价和分区成交量分时图，显示量比
- 腾讯报价默认每 2 秒刷新，当前股票分时默认每 5 秒刷新，失败后自动退避
- Webview 自选股卡片：支持名称搜索、自定义分组、折叠和持仓盈亏
- 可选的实验性代码背景分时图

## 使用

1. 打开活动栏中的“A股盯盘”。
2. 在自选股视图输入股票名称或 `600519` 这样的六位代码。
3. 点击自选股切换当前股票。
4. 执行“A股盯盘：打开分时图”，把面板拖到右侧或底部。

## 实验背景模式

执行“A股盯盘：启用实验背景模式”。该功能会备份并修改 VS Code 工作台文件，可能需要管理员权限，VS Code 更新后可能需要执行“重新安装背景组件”。

关闭或卸载前，应先执行“A股盯盘：关闭实验背景模式”。稳定面板不依赖该功能。

## 数据说明

行情优先来自腾讯财经，东方财富逐项自动兜底；搜索使用东方财富公开搜索接口。数据仅用于个人辅助查看，不保证交易所级实时性，不可用于自动交易。自选股、分组和持仓设置保存在 VS Code 本地。
