# Webview 自选股分组、持仓与分时增强设计

## 目标

将当前原生 TreeView 自选股替换为 Webview 双行卡片，支持按名称搜索、分组折叠、持仓信息和组汇总；同时让背景分时的成交量更易读，并增加量比。

## 自选股模型与兼容

保留 `StockRef` 作为行情请求的基础类型，新增 `WatchlistEntry` 元数据：`groupId`、`sortOrder`、`costPrice`、`shares`。新增 `WatchlistGroup` 保存自定义名称、排序和折叠状态。旧版 `StockRef[]` 自动迁移到“默认分组”，股票代码、名称和当前股票不变。

持仓判断为 `shares > 0 && costPrice > 0`。持仓股在所属组内优先显示；组汇总使用当前价格与昨收价加权计算涨跌幅，并汇总持仓盈亏金额。成本盈亏计算为 `(现价 - 成本价) * 股数`，比例为 `(现价 - 成本价) / 成本价`。

## Webview 自选股界面

使用 `WebviewViewProvider` 注册 `aStockWatch.watchlist`，保留活动栏和视图 ID。Webview 只负责展示和交互，扩展主进程负责持久化与行情请求。消息包括选择股票、添加搜索结果、删除、编辑分组、折叠/展开、设置成本价/股数和排序。

卡片布局：

- 组标题显示名称、股票数量、组涨跌幅和折叠按钮。
- 普通股票一行显示名称、代码、价格和涨跌幅。
- 持仓股票使用双行卡片显示现价、成本、股数、盈亏金额和盈亏比例，并默认排在组首。

搜索优先尝试代码精确匹配；名称输入使用东方财富公开搜索接口返回沪深 A 股候选，结果显示名称、代码和市场，点击后加入当前组。

## 分时成交量与量比

为 `IntradayPoint` 增加可选 `volumeRatio`，数据源不能提供标准量比时由服务按当前分钟成交量与此前最多 20 个有效分钟平均成交量计算，并在界面标注“短线量比”。成交量柱按分钟价格相对上一分钟（首根相对昨收）着色：上涨低调红色、下跌低调绿色、持平灰色。

价格和成交量采用固定分区：价格区约 78%，成交量区约 22%，中间有低透明度分隔线。价格线、均价线和零轴只绘制在价格区，成交量柱和量比标签只绘制在成交量区；时间轴放在底部。背景和独立分时面板使用同一套计算规则。

## 数据流与错误处理

Webview 接收 `watchlist` 和 `snapshot` 消息，不直接访问行情接口。搜索失败显示非阻塞错误文本；行情失败继续使用现有腾讯优先、东方财富逐项回退，并保留旧数据。持仓设置只保存本地，不上传外部服务。

## 验证

- 迁移旧版自选股数据并验证分组/持仓字段默认值。
- 测试组汇总、持仓盈亏、排序和折叠状态。
- 测试名称搜索结果解析及沪深过滤。
- 测试量比计算和成交量方向分类。
- 运行 `npm run check`、`npm test`、`npm run package`，安装新版并重新加载窗口。
