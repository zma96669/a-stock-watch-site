# 自选股数据导入导出设计

## 目标与范围

为换电脑和本地备份提供无损的数据迁移。导出内容包括自选股、股票名称与市场标识、自定义分组、折叠与排序、股票所属分组、持仓成本价和股数，以及当前选中的股票。背景组件路径、通信令牌和电脑相关状态不进入备份。

## 文件格式

使用 UTF-8 JSON 文件，扩展名建议为 `.a-stock-watch.json`。顶层包含固定格式标识、格式版本、导出时间、插件版本和数据主体。导入时严格验证结构、代码、市场、分组引用、重复 ID、重复股票、排序值和持仓数值；未知或损坏格式在修改本机数据前拒绝。

## 导入模式

- 智能合并（推荐）：分组先按 ID、再按名称匹配；缺少的分组追加。重复股票以导入文件中的分组、排序和持仓为准，本机独有股票保留。
- 完整恢复：使用备份中的分组、自选股、顺序和持仓完全替换本机配置。

导入界面先选择文件，再选择模式；完整恢复额外显示确认提示。

## 安全、恢复与入口

每次导入在插件全局存储的 `backups` 目录写入一份导入前恢复文件。应用过程中出现错误时，自动恢复导入前的自选股和当前股票。列表标题栏提供低调的“数据”入口，同时在命令面板保留直接导出和导入命令。

## 验证

测试覆盖格式往返、恶意或损坏数据拒绝、完整恢复、智能合并、重复股票以导入数据为准、导入失败回滚，以及命令和菜单声明。
