# 自选股工作台树样式设计

## 目标

把自选股分组列表调整为接近 VS Code Explorer 的原生工作台树样式，使分组层级更清晰、更低调，同时不改变自选股、持仓、关注、折叠、拖拽和行情更新行为。

## 结构与样式

- 所有分组使用固定宽度的箭头列，分组名称从同一位置开始。
- 使用 CSS 绘制轻量的折叠/展开 chevron，替换尺寸较大的实心三角字符。
- 展开分组的股票放入独立 `group-children` 容器。
- 子级容器使用 VS Code 主题变量 `--vscode-tree-indentGuidesStroke` 绘制低对比度缩进引导线。
- 每个股票行增加一小段横向连接线，并在分组层级内统一缩进。
- 行高维持紧凑，悬停和当前股票背景继续使用 VS Code 原生列表颜色。
- 持仓、“我的关注”和普通分组共用同一套树结构；持仓固定置顶逻辑不变。

## 稳定性

只在列表结构变化时重建树，实时行情仍走增量更新，不改变现有焦点、滚动和菜单关闭策略。拖拽源、拖拽目标与分组限制保持不变。

## 验证

测试覆盖工作台树 CSS、固定箭头列、子级容器、初始静态 HTML 与运行时 HTML 一致性，以及生成脚本语法。完整回归继续覆盖拖拽、关注、持仓和行情逻辑。
