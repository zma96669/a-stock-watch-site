# 背景指标快速切换设计

**日期：** 2026-08-30  
**状态：** 已按用户“按推荐方案执行”授权

## 目标

在现有代码背景分时图的指标区域中，保留成交额柱状图，并增加 MACD 指标。用户可以通过一个快捷键在“成交额”和“MACD”之间快速切换，不需要打开设置或离开编辑器。

## 推荐方案

- 主图继续显示价格线、均价线、零轴和价格区间。
- 主图下方保留同一块指标窗：默认显示每分钟成交额柱状图，切换后显示 MACD 柱体、DIF 线和 DEA 线。
- MACD 使用当前分时数据计算标准 EMA(12)、EMA(26)、DEA(9)，柱体采用 `2 × (DIF - DEA)`，指标窗始终以 0 为中心对称缩放。
- 新增命令“切换背景指标”，默认快捷键为 `Ctrl+Alt+M`。每次切换写入用户配置，因此重启 VS Code 后保留选择；命令执行后通过状态栏提示当前指标。
- 配置项 `aStockWatch.background.indicator` 支持 `volume` 和 `macd`，默认 `volume`。旧配置和旧背景加载器没有该字段时自动按成交额模式兼容。

## 数据流与边界

行情服务继续只提供已有分时点，MACD 在浏览器背景加载器内计算，不新增行情请求，也不改变 5 秒刷新频率。分时点不足或价格无效时隐藏指标窗；MACD 数值无有效变化时仍绘制 0 轴并显示 `--` 摘要，避免空白误解为没有加载。
