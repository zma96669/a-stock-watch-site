# A 股盯盘 VS Code 扩展设计

日期：2026-08-16

## 1. 目标

开发一个仅支持 A 股的 VS Code 盯盘扩展，使用户写代码时无需切换到行情软件即可查看自选股和当前股票的当日分时走势。

首版只包含基础功能：

- 一份由两种显示模式共用的自选股列表。
- 当前股票切换。
- 最新价、涨跌额、涨跌幅和成交量。
- 当日分时价格、均价线和分时成交量。
- 默认每 5 秒刷新。
- 官方 API 实现的稳定面板模式。
- 非官方注入实现的实验性代码背景模式。

首版不包含持仓、盈亏、价格提醒、券商登录、交易或自动下单。

## 2. 方案选择

采用混合式 VS Code 扩展：稳定模式使用官方 Webview API；实验背景模式向 VS Code 工作台注入透明 Canvas。两种模式共用扩展进程中的自选股、当前股票和行情服务。

没有选择纯官方方案，因为它无法真正把动态图表放到代码文字后方；没有选择独立透明窗口，因为窗口定位、多显示器、缩放和焦点处理复杂，体验不统一。

## 3. 总体架构

```text
EastMoneyProvider
        │
        ▼
QuoteService（默认每 5 秒刷新）
        │
        ├── WatchlistStore
        ├── CurrentStockStore
        ├── StatusBarController
        ├── WatchlistTreeProvider
        ├── StableChartView
        └── BackgroundBridge ──> 编辑器透明 Canvas
```

主要技术：

- TypeScript
- VS Code Extension API
- esbuild
- 本地打包的图表组件，不依赖 CDN
- VS Code `globalState` 保存自选股和当前股票
- Node.js 扩展进程统一访问行情接口

## 4. 行情数据

首版使用东方财富网页公开行情接口，不要求用户登录、Cookie 或 API Key。

### 4.1 市场代码

插件接受六位股票代码并自动转换为东方财富的 `secid`：

- 沪市：`1.<股票代码>`，例如 `600519 -> 1.600519`
- 深市：`0.<股票代码>`，例如 `000001 -> 0.000001`

首版支持沪深 A 股；代码不存在时不加入自选股。

### 4.2 自选股报价

通过 `https://push2.eastmoney.com/api/qt/ulist.np/get` 批量获取所有自选股的名称、最新价、昨收、涨跌额、涨跌幅、成交量和成交额。无论自选股数量多少，每个刷新周期只发送一个批量请求。

### 4.3 当前股票分时

通过 `https://push2his.eastmoney.com/api/qt/stock/trends2/get` 获取当前股票当日每分钟的价格、均价、成交量和成交额。数据被标准化为内部 `IntradayPoint` 类型后再交给显示层。

### 4.4 数据源边界

公开网页接口不保证长期稳定，也不提供交易所级实时性。本扩展定位为个人辅助查看工具。数据源封装在 `MarketDataProvider` 接口后，接口变化时只替换 Provider；后续可以增加腾讯行情备用源。

## 5. 状态和刷新

- 自选股与当前股票保存在 VS Code 全局状态中，不上传到自建服务器。
- 默认刷新间隔为 5 秒，并保留可配置能力。
- 面板和背景不各自请求行情，而是订阅统一的 QuoteService 状态。
- 单次请求超时约 5 秒。
- 请求失败时保留最近一次有效数据并显示延迟状态。
- 连续失败时按 5、10、20、30 秒退避；成功后恢复 5 秒。
- 非交易时间降低刷新频率并保留最后收盘数据。

## 6. 稳定模式交互

活动栏增加“A 股盯盘”入口，侧边栏显示添加按钮、自选股列表和最后刷新时间。每项显示名称、代码、最新价和涨跌幅。

点击自选股会更新统一的当前股票，状态栏、分时图和背景模式同步切换。状态栏点击可轮换自选股。

命令包括：

- 添加股票
- 删除当前股票
- 打开分时图
- 切换上一只/下一只股票
- 启用/关闭背景模式
- 重新安装背景组件

分时图使用 Webview Panel，可拖动到右侧或底部，包含最新价、涨跌幅、昨收参考线、价格线、均价线、成交量和悬停提示，并适配深浅主题。A 股遵循红涨绿跌。

## 7. 实验背景模式

背景模式仅显示当前股票，默认透明度为 0.12。首版默认绘制价格线、均价线和昨收线；成交量背景可关闭。Canvas 不接受鼠标事件，不影响代码选择、补全、终端或弹窗。

首次启用时：

1. 显示实验功能风险说明并取得确认。
2. 定位 VS Code 工作台文件，检查写权限。
3. 备份目标文件并记录原文件哈希。
4. 注入最小背景加载脚本。
5. 提示重新加载窗口。

扩展通过只监听 `127.0.0.1` 的只读本地通道向背景脚本推送当前行情，使用随机令牌路径且不接受写入。如果端口冲突则选择其他端口。

关闭时仅在目标文件仍与预期哈希匹配的情况下恢复；若 VS Code 已更新，则停止覆盖并提示重新安装背景组件。背景模式故障不得影响稳定模式。

可配置项包括刷新间隔、背景透明度、均价线、成交量和线宽。

## 8. 异常与安全

- 无效代码在加入前验证。
- 空字段、停牌、零价格和格式异常不会直接进入图表。
- 行情访问只使用 HTTPS；本地桥接只监听回环地址。
- Webview 使用严格 CSP，资源全部随扩展打包。
- 背景注入前创建可恢复备份，文件不一致时停止修改。
- VS Code 安装目录不可写时仅禁用背景模式，稳定模式继续工作。
- 扩展不收集账户、持仓、交易信息或工作区代码。

## 9. 测试

单元测试覆盖：市场代码识别、字段转换、异常值、停牌数据、自选股去重与持久化、刷新调度、退避以及当前股票同步。

集成测试使用 VS Code Extension Test Runner，覆盖自选股增删切换、状态栏更新、Webview 更新、主题变化和窗口分栏。

背景模式进行安装、关闭、恢复、升级后失效、端口占用和只读安装目录测试，并在黑暗/明亮主题、左右/上下分栏和多个编辑器中人工检查可读性。

## 10. 首版验收标准

- 稳定模式可连续运行一个交易日而不阻塞扩展宿主。
- 正常网络下行情约每 5 秒刷新。
- 切换股票后侧边栏、状态栏、分时面板和背景同步。
- 网络或数据源短暂失败不会导致 VS Code 卡顿或崩溃。
- 禁用背景模式后可恢复 VS Code 工作台文件。
- 扩展卸载前提供恢复背景组件的明确操作。
