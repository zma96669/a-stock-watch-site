# 盘中智能监控与提醒设计

**日期：** 2026-08-24  
**状态：** 已确认，待实现

## 目标

在现有 A 股自选股、持仓、大盘指数和编辑器背景行情的基础上，增加低打扰的盘中提醒。用户编写代码时无需持续盯盘，插件在行情刷新后识别价格、成交量、持仓和大盘联动异动，并通过状态栏、提醒中心或 VS Code 原生通知提示。

## 用户体验

- 股票右键菜单提供“设置盘中提醒”，规则和阈值通过紧凑的分步输入完成。
- 股票行右侧使用低饱和小圆点表示未读提醒，不使用醒目的红绿大色块。
- 侧边栏增加可折叠的“提醒中心”，分为未读、今日已触发、已暂停；默认自动收起，不替换现有自选股分组。
- 状态栏显示简短的“行情提醒 · N”。普通事件不弹窗；重要事件使用 VS Code 原生通知，并提供“查看走势”和“今日不再提醒”。默认不播放声音。
- 命令面板支持新增提醒、查看提醒、全部静默和发送测试提醒。
- 持仓股可从成本价快速生成“跌破成本价 X%”或“盈利达到 X%”规则；每条规则可启用、暂停、修改和删除。

## 规则模型

采用分层混合方案：

1. **精确规则**：突破/跌破指定价格、涨跌幅阈值、持仓盈亏比例。
2. **行情预设**：3 分钟快速涨跌、量比异常、换手率异常、最新 1 分钟成交额放大。
3. **联动规则**：个股相对上证指数、深证成指或创业板指的强弱，识别逆势走强或明显弱于大盘。

内置默认值：快速涨跌 ±1%/3 分钟、量比 2.0、分钟成交额为近期均值 2.5 倍、换手率 3%/5%/10%、指数相对强弱 1.5%；接近目标价默认距离 0.5%。用户可覆盖阈值和提醒等级。

## 数据流与状态

行情刷新继续复用腾讯财经主源和东方财富兜底，不为每条规则单独发请求：

```text
行情刷新 → 更新个股/指数 → 本地规则计算 → 越线判断 → 冷却去重 → 状态栏/通知
```

- 引擎在内存保留最近 5–15 分钟的轻量分时快照，用于快速涨跌和分钟放量计算。
- 配置（规则、阈值、启用状态）进入现有本地导出和 GitHub 同步。
- 未读状态、冷却时间和当日触发记录仅保存在本机，不跨设备同步；交易日切换自动清理。
- 首次越线立即触发；条件持续成立不重复；恢复正常后再次越线可重新触发；同一规则设置 10 分钟冷却。

## 交易时段与异常处理

- 非交易日、开收盘外、午休、停牌时不触发行情异动提醒。
- 行情超过有效期时显示“数据延迟”并暂停依赖实时数据的规则。
- 字段缺失只跳过依赖该字段的规则；价格类规则仍可工作。
- 主备数据源切换不会重复触发同一事件。
- 根据主板、创业板、科创板、北交所和 ST 股票识别不同涨跌停制度，后续可扩展接近涨停/跌停规则。

## 测试与验收

- 覆盖阈值边界、二次越线、10 分钟冷却和交易日重置。
- 使用模拟行情验证价格、量比、分钟放量、换手率、持仓盈亏和指数联动。
- 覆盖断网、字段缺失、数据延迟、数据源切换、导入导出和 GitHub 同步。
- 提供“发送测试提醒”命令，安装 VSIX 后可立即验证通知链路。
- 验收标准：普通提醒不弹窗且可在提醒中心查到；重要提醒只在首次越线弹出；恢复后重新越线可再次触发；原有自选股、分组、持仓、大盘和背景功能不回归。

## 后续演进

第一版先采用固定规则与轻量快照，后续可在不改变规则模型的前提下加入波动率自适应、盘后复盘、公告/新闻事件和更丰富的 K 线分析。
