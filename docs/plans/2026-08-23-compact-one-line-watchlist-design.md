# 自选股紧凑单行布局设计

## 目标

恢复自选股列表的紧凑单行展示，避免成交额、分组选择和操作按钮让每只股票占据两行。

## 布局

- 每只股票固定显示：股票名称、代码、最新价、涨跌幅。
- 点击整行继续切换当前股票。
- 成交额、持仓成本、股数和持仓盈亏放入鼠标悬停提示，不占用常驻空间。
- 分组移动、设置持仓和删除收进每行右侧低调的 `···` 菜单。
- 分组标题继续支持折叠、重命名，并显示股票数量和组涨跌幅。

## 兼容性与验证

不更改已有分组、自选股和持仓存储结构，也不改变行情刷新流程。测试覆盖最终 Webview 脚本语法、单行 DOM 结构和隐藏操作菜单，避免交互脚本再次整体失效。
