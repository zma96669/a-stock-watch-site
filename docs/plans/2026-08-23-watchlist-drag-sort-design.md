# 自选股拖拽排序设计

## 范围

- 顶部“持仓”区域固定，持仓节点和其中的股票均不支持拖拽。
- 普通分组支持上下拖动排序。
- 普通股票支持组内排序和跨普通分组移动。
- 折叠的普通分组可以接收股票，股票拖入后追加到该组末尾。

## 交互

- 只允许从普通分组标题和普通股票行开始拖动。
- 拖动时使用低调的插入线提示目标位置，不增加大面积高亮色块。
- 股票拖到分组标题时追加到该分组末尾；拖到股票上方或下方时插入对应位置。
- 分组只接受分组拖拽，股票目标只接受股票拖拽，避免混淆。
- 拖拽过程中不触发股票选择和操作菜单。

## 数据与验证

扩展侧新增分组排序和股票精确放置方法，统一重新编号 `sortOrder` 并持久化。测试覆盖同组排序、跨组移动、分组排序、非法目标无操作、Webview 消息与最终脚本语法。
