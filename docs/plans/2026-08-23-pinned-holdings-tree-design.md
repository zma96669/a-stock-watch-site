# 持仓置顶与树状分组设计

## 目标

将持仓从普通分组排序中独立出来，在列表顶部提供固定的“持仓”树节点；普通分组改为低调的无边框树状列表。

## 行为

- 顶部固定显示“持仓”节点，节点内展示所有同时配置了成本价和股数的股票。
- 持仓股仍保存原分组归属，但从普通分组内容中排除，避免重复显示。
- “持仓”节点可折叠，折叠状态只保存在 Webview 会话中，不改变普通分组的持久化结构。
- 普通分组用缩进箭头、名称、数量和汇总涨跌幅展示，不使用卡片边框。
- 价格、涨跌幅、组汇总和持仓盈亏统一使用普通前景色，不再使用红绿颜色。

## 兼容性与验证

保持现有分组、自选股、持仓和行情数据格式，报价仍采用增量更新。测试覆盖持仓置顶、普通分组排除持仓、树状无边框样式和颜色 class 不再应用。
