# A 股盯盘产品官网设计

## 目标

为 A 股盯盘 VS Code 插件提供一个可直接用于演示和推广的静态官网，突出“行情融入工作台、低打扰、本地优先、可跨设备同步”的产品定位。

## 体验方向

- 深色开发者工作台风格，使用电光蓝、青色和紫色作为少量霓虹强调色。
- Hero 区域用粒子背景、网格光晕和动态分时曲线建立第一印象。
- 用真实插件截图作为证据，避免只展示概念 Mockup。
- 滚动 reveal、数字计数、卡片 spotlight/轻微 3D 倾斜等动画增强观赏性。
- 移动端降级粒子数量和动画强度，保证可读性和性能。

## 页面结构

1. Hero：定位文案、版本/测试/数据源指标、双 CTA、产品工作台视觉。
2. 场景：不离开代码、低打扰、数据可迁移三张卡片。
3. 功能：实时分时、树状工作台、持仓盈亏、GitHub 私有同步。
4. 行情演示：动态价格、涨跌幅、分时线、成交量和量比。
5. 产品截图：真实插件截图与工作台说明。
6. CTA/Footer：安装 VSIX、查看 README、免责声明。

## 技术方案

- 独立 `website/` 目录，纯 HTML/CSS/原生 JavaScript，无重型运行时依赖。
- Canvas 粒子系统支持漂浮、连线、鼠标排斥；使用 prefers-reduced-motion 和移动端粒子降级。
- SVG 分时曲线通过 path-dashoffset 和 JS 数据更新实现动态效果。
- IntersectionObserver 驱动滚动入场；CSS 变量实现鼠标 spotlight 和卡片 tilt。
- 页面引用 `website/assets/` 中的真实插件截图。

## 验收标准

- 双击或静态服务器打开 `website/index.html` 可完整浏览。
- 首屏有粒子和动态行情视觉，导航锚点可用，移动端不横向溢出。
- 无外部图片或字体依赖时仍可正常显示；截图加载失败有占位风格。
- 保留“数据仅用于个人辅助查看，不保证交易所级实时性”的合规提示。
