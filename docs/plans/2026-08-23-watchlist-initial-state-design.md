# 自选股 Webview 初始状态修复设计

## 问题

自选股 Webview 以空数组启动，首次显示依赖扩展主进程发送 `postMessage`。当首次消息未送达或页面脚本在消息到达前异常时，列表区域会保持完全空白，甚至没有空状态提示。

## 设计

- 扩展侧使用唯一的 `statePayload()` 生成分组、自选股、当前股票和行情快照。
- 生成 Webview HTML 时，把该状态安全序列化并直接嵌入页面脚本；页面注册事件后立即执行首次渲染。
- 保留 `ready` 消息与后续 `state` 消息，用于页面启动后的状态校准和实时更新。
- 捕获同步脚本错误与未处理 Promise 拒绝，在 Webview 中显示可见错误，避免再次出现无提示空白。
- 不修改 `globalState` 数据格式，不迁移、不清空现有分组、自选股或持仓数据。

## 安全与验证

内联 JSON 转义 `<`、`>`、`&`、U+2028 和 U+2029，防止股票名称等文本提前结束脚本标签。回归测试覆盖初始状态嵌入、立即渲染、错误处理和序列化边界字符。
